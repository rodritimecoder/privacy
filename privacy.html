Privacy Policy for rclone Personal Drive Sync

Effective Date: September 28, 2026

rclone Personal Drive Sync ("we", "our", or "us") operates this personal storage integration tool. This policy explains our handling of information accessed through Google OAuth services.

1. Information We Access and Process

We access only the information required to execute file synchronization operations:

  • Account Identification: Email address and basic profile identifier to authenticate the user session.
  • Google Drive Files: File metadata, contents, and directory hierarchies specifically designated by the user for download, upload, or local mirroring.
  • System Logs: Local diagnostic error output generated during file transfer tasks, stored solely on the user's host device.

2. Purpose of Processing

The accessed data is used exclusively to:

  • Transfer and mirror designated files between the user's local disk and Google Drive.
  • Authenticate and refresh secure OAuth 2.0 access credentials.
  • Provide operational status logs directly to the user.

3. Google API Services User Data Policy (Limited Use)

rclone Personal Drive Sync's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • We do not use Google user data to serve advertisements, including personalized, retargeted, or interest-based ads.
  • We do not sell Google user data to third parties.
  • We do not transfer or use Google user data for training non-personalized artificial intelligence (AI) or machine learning (ML) models.
  • We do not permit human access to your Google user data unless required by applicable law, needed for security investigation, or explicitly approved by you for technical troubleshooting.

4. Storage and Credential Security

OAuth tokens (client IDs, client secrets, and refresh tokens) are maintained locally on the user's secured local filesystem in configuration files. Tokens are never transmitted to external third-party servers.

5. Data Retention and Revocation

We do not store Google user data on any centralized servers. You may revoke the application's access token at any time through the Google Account Permissions Manager. Revoking access halts all synchronization actions immediately.
