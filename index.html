rclone Personal Drive Sync

Personal storage synchronization tool linking local disks to Google Drive.

About the Application

rclone Personal Drive Sync connects a local Linux storage system directly with Google Drive. It allows authorized users to manage, synchronize, mirror, and back up personal files securely across local SSDs and cloud storage.

Key Features

  • Bidirectional Synchronization: Synchronizes personal directory structures between local storage and Google Drive.
  • Local Caching: Maintains efficient local cache layers for fast read and write operations.
  • Encrypted Transfers: Handles file streams via standard TLS encryption directly between client and cloud endpoints.

Google Integration & Scopes Transparency

To perform storage management tasks, this application requests user authorization via OAuth 2.0. We request access strictly to deliver storage synchronization functionality:

  • Google Drive API (https://www.googleapis.com/auth/drive): Requested strictly to read, write, upload, and update files and folders selected by the user for synchronization with their local computer.
  • Basic Profile (openid, email): Requested to identify the active Google account and verify authorization status.
Data Safety & Protection:

This application operates solely as a synchronization client. We do not sell user data, share files with third parties, display advertisements, or use Google user data to train generalized AI or machine learning models.
